# readme-generator

This repository holds two unrelated things:

- **README generator** (`index.js`, at the root): a small Node CLI that prompts for project details
  and writes a README.
- **Don't Die at Work Today** (`dont-die-at-work/`): the pipeline for a YouTube channel of
  animated workplace-incident reconstructions. Its rules, template and folder structure are in
  @dont-die-at-work/CLAUDE.md and apply to all work in that folder.
